# Knowledge Base

Durable domain knowledge — terms, module boundaries, business rules,
conventions — curated by humans. The BA agent reads this file on every
`draft` run for context, but never writes to it. To update it, hand-edit
this file directly and commit the change.

Agent-derived knowledge accumulated from *approved* requirements lives in
`context/context-lake.md` instead — see that file and
`skills/update-context-lake.md`.
