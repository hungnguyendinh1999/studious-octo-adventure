# Meeting Notes — Todo App Follow-up

Quick notes from the follow-up call with the ops team:

- They actually do want *some* visibility across users — team leads should
  be able to see how many open tasks each person has (just a count, not
  the task details).
- Due dates: should support optional reminders, not just a date field.
- Someone mentioned SSO login would be nice eventually, but that's not
  urgent for v1.
